Build Order Rationale

Why This Sequence

Order is driven by (1) which feature removes the most hours from a CA firm's month, and (2) which is the largest gap vs what competitors already ship.

RankFeatureBenchmarkRationale
1Tally ingestion + validationFireAI, AccomationEverything downstream needs it — no point building before data lands clean.
2Bank statement + OCR extractionProvi AI, Suvidha, AI AccountantBiggest single hour sink (167 hrs/mo per 100-client firm).
3Transaction categorization (TDS + cap/rev)Provi AI, Febi.aiAttack where competitors warn buyers to "check" — their weakness.
4GST reconciliation engineGSTAgent, FireAI, CORAAThe 14th-of-month problem. Highest willingness to pay.
5Rule 37A + IMS trackingGSTAgent (37A), CORAA (IMS)Beat GSTAgent where weak; match CORAA where it wins.
6Versioned rulesets + exceptions + audit trailFireAI, CORAATrust feature — converts "AI output" into defensible work product.
7Deadline engine + doc collectionFinexo, Aalekh, MNBCheap, huge perceived value, wins the "single source of truth" story.
8GST/ITR filing assistantAalekh, Provi AI ✅ (Sprint 5)Completes the compliance loop.
9TDS + AIS cross-checkProvi AI ✅ (Sprint 5)Quarterly return prep.
10Audit engine (full-population, explainable)CORAAHighest price point (₹30K+/yr). Build when data moat exists.
11Cited tax researchTaxmann.aiLowest urgency — Taxmann has a content moat; compete on price + integration.
12Benchmarking, API, ecosystemNobodyPure differentiator. Network effects kick in.

Core Thesis

The firm that owns the data layer for Indian CA compliance owns the market. Data in → categorize → reconcile → file → audit → advise. Each stage unlocks the next; we never build stage N+1 before stage N works at competitor parity on real client data.
