1

Sandbox by Quicko — LIVE API keys

Pay per call~20 min

Unlocks: live GSTIN verification, GSTR-2B reconciliation jobs, TDS analytics/FVU, and e-invoice through the GSP.

platform/.env
MYCA_GSP_BASE_URL=https://api.sandbox.co.in
MYCA_GSP_ENV=live
MYCA_GSP_LIVE_API_KEY=paste-key
MYCA_GSP_LIVE_API_SECRET=paste-secret
Two catches: GST filing APIs (GSTR-1 save/file, taxpayer OTP) go through a GSP — Sandbox covers that but may need their ASP/GSP onboarding, not just a key. And Sandbox publishes no income-tax calculator endpoint, so that one stays off.
2

NIC e-invoice (IRP) — direct

Free~25 min

Unlocks: generating a real IRN/signed QR directly with the Invoice Registration Portal (separate from Sandbox).

Why the .cer matters: NIC requires credentials encrypted with its RSA public key. MyCA fails closed if the key is missing rather than sending a password in the clear.
3

Email — deploy the bundled relay

Free tier~15 min

Unlocks: real invoice/reminder emails (and the outbox "Send"). MyCA posts JSON to a relay you own — a Worker is already written at email-relay/.

terminal — in email-relay/
npx wrangler email sending enable yourfirm.in
npx wrangler secret put RELAY_TOKEN
npm install
npm run deploy
platform/.env
MYCA_EMAIL_FROM=compliance@yourfirm.in
MYCA_EMAIL_RELAY_URL=https://myca-email-relay.<subdomain>.workers.dev
MYCA_EMAIL_RELAY_TOKEN=the RELAY_TOKEN you set
No Cloudflare? Point MYCA_EMAIL_RELAY_URL at your own function that accepts the same {from,to,subject,text} JSON (SES, Postmark, Resend…).

Finish: turn it on and verify

Once the keys above are in platform/.env:

terminal — in platform/
npm run check:env      # which keys are still blank
npm run setup:env      # interactive wizard (optional)
node src/server.mjs    # then open http://127.0.0.1:4780

In the app: APIs tab → Run integration doctor tells you, per provider, whether it's reachable and exactly what's missing. When you're ready for outbound calls, set MYCA_ENABLE_LIVE_CALLS=1.
