# End-to-end results

One table per run: a build on a device, by one tester. Step ids come from
[`E2E-CHECKLIST.md`](E2E-CHECKLIST.md). Record what happened, not what should have happened, and
link every failure to its `type:bug` issue. Newest run at the top. Never paste a sign-in code,
token or password here.

## Run template

Copy this block for each run.

```
### <date> · <build version, from Businesses → About this app> · <device slot and model> · Android <version> · <tester>

Backend: staging | production · Network: N1 | N2 | N3

| Step | Result | Notes | Issue |
|---|---|---|---|
| L1 | pass / fail / blocked / skipped | | |
```
