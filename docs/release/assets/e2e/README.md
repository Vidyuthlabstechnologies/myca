# Sample files for the end-to-end checklist

Small files the testers upload in steps U1 to U5 and E3 of `docs/release/E2E-CHECKLIST.md`: a bill
photo, a PDF bill, a bank statement CSV, a GSTR-2B JSON and one file over 8 MB. Use made-up
businesses and people only. A file over 8 MB is not committed; make one on the phone or with
`head -c 9000000 /dev/urandom > big.bin`.
