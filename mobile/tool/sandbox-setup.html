MyCA — Sandbox credentials

Drop the sandbox values once. This page stays on this machine, makes no network calls, and never sends anything anywhere. Paste into the fields, copy the generated cloud/.env and the flutter run line, and start testing.

Sandbox means phone codes print to the API terminal, channel pulls are a dry run, and filing stays off. Live keys do not belong here.

3 · Official portals and channel credentials

Where each secret comes from, and where it is pasted. Nothing here goes in the app build; app-side defines carry only the two client ids.

Tax (per business, owner): Sandbox by Quicko GSP — developer.sandbox.co.in → API key + secret (test, then live) → desktop Govt tab or platform/.env as MYCA_GSP_TEST_API_KEY / SECRET and MYCA_GSP_LIVE_API_KEY / SECRET, MYCA_GSP_ENV=test|live. NIC e-invoice / e-way bill IRP — sandbox: einv-apisandbox.nic.in (User Type Tax Payer, GSTIN + trade name + GST-registered mobile, OTP) → Client ID + Client Secret, then a GSTIN username + password, plus the IRP .cer public key → desktop Govt tab (govt.json, sandbox first). Production IRP credentials come from einvoice1.gst.gov.in after on-boarding with static IPs and a test report. GST returns are viewed through the GSP; filing itself stays on gst.gov.in or with the CA and the ARN is recorded back.

Messaging (cloud .env, fields below): SMS — MSG91 (India): Account → API access → authkey + OTP template id, MYCA_SMS_PROVIDER=msg91; or Twilio: account SID + auth token + from number. WhatsApp Cloud API — Meta developers → WhatsApp app → phone number id + permanent access token + verify token + app secret. Email relay + inbound — relay URL + token + from address, inbound domain for per-key addresses.

Connectors (per business, Connections screen, dry run until pulls are enabled): Amazon SP-API — Seller Central → Apps and Services → Develop apps → private app → LWA client id + secret + refresh token, marketplace A21TJRUUN4KGV, region IN. Shopify — dev store → Develop apps (read_orders, read_shopify_payments_payouts) → Admin API token, shop host. Razorpay — test key id (rzp_test_…) + secret. Zoho — API console Self Client → code for ZohoBooks.fullaccess.all → refresh token + numeric org id, dc=in. US channels (Plaid, TaxJar, Gusto, Track1099) need the global flavor and are out of scope for India testing.

Desktop-local only: Tally (MYCA_TALLY_HOST/PORT), model key (MYCA_MODEL_API_KEY) for bill reading and chat.
